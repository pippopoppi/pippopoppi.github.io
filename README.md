# Pippo Poppi Games — home

La pagina di ingresso con i link a tutti i giochi: https://pippopoppi.github.io/

Una sola pagina statica (`index.html`), nessuna build. Ogni scheda usa l'icona del gioco
dal suo repo, mostra quante volte è stato giocato (contatore GoatCounter) e, per i giochi
con classifica mondiale, chi è al primo posto (Worker `ranking`).

Per aggiungere un gioco: copia una scheda in `index.html`, cambia link, icona, titolo e
descrizione, e aggiungi `data-rank="1"` se ha la classifica mondiale.
